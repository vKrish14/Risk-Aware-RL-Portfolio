# Reference repositories and sources

Inspected for Phase 1 on 2026-10-10. The seven supplied Git remotes responded to `git ls-remote ... HEAD`, which verifies public Git transport access at inspection time; no repository was cloned. The GitHub unauthenticated API returned rate-limit errors during metadata inspection; public GitHub pages were used to inspect README excerpts, root trees, and visible license links. Where exact license text or dependency versions were not available on those pages, this is explicitly marked unknown. Reported results in those projects are not evidence about this project.

## Technical documentation and compatibility

Primary documentation links supplied by the project: [Stable-Baselines3 PPO](https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html), [Gymnasium](https://gymnasium.farama.org/), [FastAPI](https://fastapi.tiangolo.com/), [Streamlit](https://docs.streamlit.io/), [yfinance](https://github.com/ranaroussi/yfinance), and [PyPortfolioOpt](https://pyportfolioopt.readthedocs.io/). Version metadata was checked against PyPI JSON on 2026-10-10. Current releases of Gymnasium, SB3, Torch, FastAPI, Streamlit, and Pydantic declare Python >=3.10; Pandas declares >=3.11. Latest NumPy requires >=3.12, so the project leaves NumPy unpinned below 3 and relies on pip's Python-aware wheel/version resolution. Python 3.11–3.13 is the declared range; installed runtime verification is performed separately by `scripts/verify_environment.py`.

## Originality and reuse record

No external source code has been copied into this project. The repositories are architectural/research references only. Future code reuse requires inspecting the exact source file and license, recording attribution, and reviewing license compatibility before integration.
